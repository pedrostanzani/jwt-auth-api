# AWS Deployment

The second stage of the project consists of deploying the developed API to AWS 
(Amazon Web Services).

The deployment was performed using Amazon Elastic Kubernetes Service (EKS), `eksctl` and `kubectl`, 
in addition to creating a distribution with Amazon CloudFront.

## EKS Application Deployment

Amazon Elastic Kubernetes Service (EKS) is a managed service from Amazon Web Services (AWS) that makes it easy to run Kubernetes clusters in the cloud.

Five YAML files were created for the application's deployments and services. They are:
- namespace.yaml 
- jwt-api-deployment.yaml 
- jwt-api-service.yaml 
- postgres-deployment.yaml 
- postgres-service.yaml

These files are available [on GitHub](https://github.com/pedrostanzani/jwt-auth-api/tree/main/deployment).

<Steps>
### Create the cluster with `eksctl`
 
```bash
eksctl create cluster 
  --name jwt-app-cluster 
  --region us-east-1 
  --nodegroup-name standard-workers 
  --node-type t3.medium 
  --nodes 2 
  --nodes-min 1 
  --nodes-max 3 
  --managed
```
 

### Create the Kubernetes namespace
 
```bash
kubectl apply -f namespace.yaml
```
 
### Deploy the PostgreSQL service
 
```bash
kubectl apply -f postgres-deployment.yaml
kubectl apply -f postgres-service.yaml
```

### Deploy the API server
 
```bash
kubectl apply -f jwt-api-deployment.yaml
kubectl apply -f jwt-api-service.yaml
```

### All set!
 
Check if the pods are running correctly:

```bash
kubectl get pods -n jwt-app
```

</Steps>
 
## CDN Configuration with Amazon CloudFront

As a way to make the API available with HTTPS access without the need for an SSL 
certificate, a distribution was created using Amazon CloudFront — an AWS Content 
Delivery Network (CDN) service.
