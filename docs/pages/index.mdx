# Introduction
 
This project was developed for the Cloud Computing class at Insper. It demonstrates an API that implements JWT-based authentication. It was built with ElysiaJS, Bun and TypeScript.

## Technologies used

The following technologies were used:
- **ElysiaJS**: framework for building web servers
- **Bun**: JavaScript runtime and package manager
- **TypeScript**: programming language with static typing
- **Prisma**: ORM for Node.js and TypeScript

And the following libraries were used to develop the web scraping service:
- **Cheerio**: library for HTML parsing
- **Axios**: HTTP client for making web requests

## API Endpoints

The API offers authentication and data query endpoints. Access the [API documentation](/swagger#tag/default/POST/register) to view the list of endpoints.
