# Installation
 
Follow the instructions below to install and run the project.


## Local installation

<Steps>
### Download
 
Download the `compose.yaml` file from [this link](https://raw.githubusercontent.com/pedrostanzani/jwt-auth-api/refs/heads/main/compose.yaml) and store it in an empty directory.
 
### Execution with Docker Compose
 
Run the command below in the terminal of the directory where the `compose.yaml` file was stored:
```bash
docker compose up
```

### All set!
 
Now you can access the API at [http://localhost:3000](http://localhost:3000).

</Steps>
