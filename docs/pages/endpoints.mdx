# API Endpoints

The API offers authentication and data query endpoints.

## Swagger

The API endpoint documentation was developed with Swagger and Scalar and can be accessed [at this link](/swagger).
 
## List of endpoints

### Register user

- Endpoint: `POST /register`
- Description: endpoint for creating new users.

### Login

- Endpoint: `POST /login`
- Description: authentication endpoint for existing users.

Authentication is performed with email and password. This endpoint returns a JWT token that should be used in requests to the data query endpoint.

<div className='mt-6'>
  <Cards.Card
    icon={<Box />}
    title="View in Swagger"
    href="/swagger#tag/default/POST/login"
    arrow
  />
</div>

### Query data

- Endpoint: `GET /query`
- Description: headlines query endpoint.

This endpoint returns a list of BBC headlines. These headlines are cached (in memory) and update every hour.
